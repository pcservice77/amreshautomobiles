# **App Name**: Amresh Volt

## Core Features:

- Electric Scooty Showroom Catalog: A public-facing landing page displaying scooter models with high-quality images, range specs, and pricing details.
- Admin Inventory Controller: A secure portal for showroom managers to add, update, or remove electric scooter models and their specific features.
- Smart Spec Copywriter: A generative AI tool used by admins to instantly create professional, persuasive product descriptions based on a scooter's technical specifications.
- Cloud-Based Auth & Permissions: User sign-in system using Firestore to manage specific access roles, allowing general users to view products while granting admin status for management.
- Digital Billing Engine: An admin tool to generate digital sales bills by capturing customer details (Name, Phone, Address), ID types (Aadhar, PAN, Passport, DL), and vehicle data (Model, Chassis Number).
- Sales History Manager: A central database store to archive and search customer purchase history, managing all past transactions and scooter delivery data.

## Style Guidelines:

- Primary Color: Electric Indigo (#708FFF), a vibrant, high-tech hue symbolizing clean energy.
- Background: Dark Navy Charcoal (#14161F) for a premium, contemporary automotive dealership atmosphere.
- Accent: Bright Cyan (#24C0FF), used for calls-to-action and key highlights to suggest motion and velocity.
- Headlines: 'Space Grotesk', a tech-focused sans-serif to convey precision engineering.
- Body Text: 'Inter', an objective sans-serif providing high readability for technical scooter specifications and legal billing documents.
- A minimalist, grid-based showroom layout that focuses on product photography and high-contrast spec cards.
- Smooth, fluid transitions between product filters and subtle fade-ins for admin dashboard data visualizations.
